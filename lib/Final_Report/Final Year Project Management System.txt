Abstract:
OrderVista is a centralized platform that empowers consumers to track, organize, and manage all their
upcoming online orders from various retailers and couriers in one unified dashboard. By leveraging machine
learning for image/text extraction and large language models for intelligent parsing and assistance,
OrderVista simplifies the process of monitoring deliveries, handling returns, and staying informed about
incoming packages. Users can import order data via email, screenshots, or photos of receipts/labels, making
the platform highly accessible and retailer-agnostic.

Outcome



Objectives:
To develop a seamless web/mobile app for consumers to consolidate and visualize all upcoming orders
and deliveries.
To integrate image recognition (OCR, barcode/label reading) and LLM-driven parsing for easy order
entry from any source.
To provide smart assistance for delivery timelines, return management, and proactive notifications.
To enhance user experience through natural language queries and interactive dashboards.
Deliverables:
A responsive mobile application (OrderVista) with user authentication and dashboard.
Modules for importing orders via email, image upload, and screenshot parsing.
Integrated OCR and LLM pipeline for extracting and organizing order details.
Timeline/calendar visualization and notification system for deliveries.
Return management assistant and FAQ/chatbot for user queries.
Documentation and user guide.
